Estado del sistema

Diagnóstico de base de datos, impresión, bloqueo y copias de seguridad. No muestra secretos.

Red local (LAN)

El servidor escucha en todas las interfaces. Los demás dispositivos entran por la IP del equipo servidor y el puerto configurado (por defecto 8080), por ejemplo http://192.168.1.50:8080.

Recuerde permitir el puerto en el firewall de Windows y no exponer la aplicación directamente a Internet.
